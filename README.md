# GTA 6 Co-pilot

A dashboard of GTA 6 story-mode finds: what's new, trending, open-world tips, glitches, mission branches, missables and patch notes. A scan updates it every 4 hours.

Open the page: https://bobloblaw55.github.io/gta6-hub/

Light spoilers only. Story-related items are hidden behind a click.

All content lives in the JSON block at the top of `index.html` (`<script id="data">`). The scan replaces only that block.
