# Feeling Sixy with my Clam

A GTA 6 story-mode co-pilot: what's new, trending, open-world tips, glitches, mission branches, missables and patch notes. A scan updates it every 4 hours.

Open the page: https://feelingsixywithmyclam.com (also https://bobloblaw55.github.io/gta6-hub/)

Light spoilers only. Story-related items are hidden behind a click.

All content lives in the JSON block in `index.html` (`<script id="data">`). The scan replaces only that block.
